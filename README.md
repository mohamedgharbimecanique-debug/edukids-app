# EduKids

Application éducative web pour les enfants du CP au CE2.

## Déploiement

Le dépôt est configuré pour GitHub Pages avec GitHub Actions. Dans GitHub, ouvrir **Settings > Pages**, puis sélectionner **GitHub Actions** comme source si nécessaire.

Adresse attendue : `https://mohamedgharbimecanique-debug.github.io/edukids-app/`.

## Structure

- `index.html` : accueil et choix du niveau.
- `cp.html`, `ce1.html`, `ce2.html` : activités par niveau.
- `css/`, `js/`, `images/`, `sons/` : ressources du projet.

Le projet reste en développement et pourra recevoir d’autres améliorations.
